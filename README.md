# Consumer Behavior & Shopping Analytics Dashboard 📊

An end-to-end interactive 3-page Power BI dashboard designed with a custom dark-mode neon theme to analyze customer demographics, omnichannel spending dynamics, behavioral attributes, and fulfillment logistics.

![Dashboard Preview](your-dashboard-screenshot-link-here.png)

## 📌 Key Highlights & Features
- **3-Page Dynamic Navigation:** Built-in custom neon UI container layouts for macro overview, granular segment deep-dives, and customer logistics.
- **Data Modeling & DAX:** Star schema design with standard dimension tables (`Dim_Gender`, `Dim_Income`, `Dim_City_Tier`, `Dim_Age_Group`, `Dim_Preference`, `Dim_Date`) linked to core fact metrics.
- **Omnichannel Spend Analysis:** Tracks online vs. physical store spend gaps, spend-to-income ratios, and demographic preferences.
- **Behavioral Profiling:** Evaluates scores across impulse buying, brand loyalty, payment trust, discount sensitivity, and tech savviness.
- **Logistics & Satisfaction:** Analyzes return frequencies, delivery lead times, and digital engagement hours.

## 🛠️ Data Model & Tech Stack
- **Business Intelligence Tool:** Power BI Desktop
- **Data Modeling:** Star Schema (1-to-Many relationships)
- **Calculations:** DAX (Time Intelligence, Dynamic Ranking, Demographic Aggregations)
- **UI Design:** Custom Neon Dark Theme Layouts (16:9 Canvas)

## 🚀 Pages Breakdown
1. **Executive Overview:** High-level channel preference distribution, demographic spend trends, and digital activity gaps.
2. **Customer Segment & Trend Details:** Granular multi-level matrix tables, behavioral profile spider/bar breakdowns, and operational metrics.
3. **Customer Logistics & Satisfaction:** Delivery turnaround times, product return frequency rates, and regional fulfillment dynamics.
